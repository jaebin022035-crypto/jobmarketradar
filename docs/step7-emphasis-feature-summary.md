# Step 7 · 항목별 강조 포인트 (AI 작성 요구사항) — 작업 요약

> **작업일**: 2026-08-10
> **기능**: 프로필에 여러 기술/경험이 있을 때, AI가 한 경험을 자소서 5개 항목에 반복하는 문제 해결
> **배포**: 로컬 + vcluster(`kopo13-jobradar.std.kopoctc.kr`) 모두 완료

---

## 1. 배경 (해결한 문제)

**기존 한계**: 프로필에 `experience`, `skills`, `portfolio` 가 각각 하나의 텍스트 덩어리로 들어있고,
`buildPrompt()` 가 이를 한 번에 프롬프트로 조립 → AI가 **가장 강렬한 경험 하나를 5개 항목에 반복해서 우겨넣는 경향**.

**목표**: 자소서 작성 전에 "이 자소서에서는 각 5개 항목에 어떤 기술·어떤 프로젝트 일화를 배정할지" 정해주면,
AI가 중복 없이 다양한 경험을 항목별로 나눠 쓰도록.

## 4. 핵심 로직 — 프롬프트에 강조 포인트 반영 (`ai.js`)

emphasis JSON 이 있으면 프롬프트에 아래 블록 추가:

```
[항목별 강조 포인트 — 지원자가 직접 지정한 작성 가이드, 반드시 반영할 것]
- 지원동기(motivation): <사용자 입력>
- 직무경험(career): <사용자 입력>

★ 경험 배정 원칙 (매우 중요):
- 위 강조 포인트에 적힌 기술·프로젝트·일화를 그 항목의 중심 소재로 사용하라.
- 지원자는 [지원자 정보]에 여러 기술과 경험을 보유하고 있다. 각 항목에는 서로 다른 경험을 배정하여
  자소서 전체가 다양한 역량을 보여주도록 하라. 한 기술/경험을 여러 항목에 반복하지 말 것.
- 강조 포인트를 비운 항목은 [지원자 정보]에서 그 항목에 가장 어울리는 경험을 자유롭게 선택하라.
```

emphasis 가 없으면(기존 프로필) 이 블록 생략 → **기존 동작 100% 유지**.

## 5. 데이터 구조

`profiles.emphasis` (TEXT, JSON):
```json
{
  "motivation": "클라우드 플랫폼에 기여하고 싶은 동기 + 사이드 프로젝트 'X' 경험",
  "growth": "팀 프로젝트에서 갈등을 해결하며 키운 협업·소통 능력",
  "career": "Spring 기반 결제 시스템 구축·장애 대응 경험 중심"
}
```
- 비운 항목은 객체에서 제외 (서버에서 빈 값 정규화 → 전부 비었으면 `null`)

## 7. 호환성

- **기존 프로필**: `emphasis = null` → 프롬프트에서 `[항목별 강조 포인트]` 블록 생략 → 기존 동작 완전 유지
- **기존 자소서**: 영향 없음
- **마이그레이션**: 서버 기동 시 자동 (init 시 ALTER), 별도 작업·롤백 불필요

## 8. 사용 방법 (사용자 관점)

1. 이력서 관리 → 프로필 편집 (또는 새 프로필)
2. 폼 하단 **"🪄 AI 작성 요구사항 (항목별 강조 포인트)"** 섹션에서 각 항목에 강조할 기술/일화 입력
   - 예) ① 지원동기 → "클라우드 동기 + X 프로젝트"
   - 예) ④ 직무경험 → "Spring 결제시스템 구축"
3. 저장 → 이 프로필로 만드는 모든 자소서에 강조 포인트 적용
4. 자소서 생성 시 AI가 각 항목에 지정한 경험을 중심으로, 서로 다른 경험을 배정해 작성
